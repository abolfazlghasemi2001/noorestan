# بازطراحی بازی‌های نورستان

شاخهٔ `refactor/game-catalog` فازهای اولیهٔ بازطراحی است. رفتار فعلی نسخهٔ اصلی دست‌نخورده مانده و تغییرات ابتدا روی شاخهٔ جدا انجام می‌شوند.

## انجام‌شده

1. رجیستری واحد بازی‌ها در `games/catalog.js`.
2. اتصال صفحهٔ `games/index.html` به رجیستری و فیلتر موضوع/مهارت.
3. قرارداد مشترک نتیجه در `games/result-contract.js` با سازگاری برای API قدیمی `G.result`.
4. آداپتور مهاجرت در `games/result-bridge.js`.
5. نگاشت کلیدهای قدیمی `ayahbuilder_*`، `hadithrush` و `noorpairs_*` به شناسه‌های استاندارد.
6. تست پوشش مهاجرت سه بازی در `tests/game-migration.test.js`.
7. نگهبان بارگذاری در `tools/verify-game-contract.js` برای جلوگیری از اجرای ناقص bridge.

## وضعیت اتصال اجرایی

سه صفحهٔ فعلی هنوز فقط `common.js` را بارگذاری می‌کنند. نگهبان عمداً تا زمان اتصال واقعی فایل‌ها قرمز می‌ماند؛ این بهتر از آن است که مهاجرت نصفه و بی‌صدا وارد نسخهٔ اجرا شود.

## قدم بعدی

اتصال سه فایل با ترتیب `common.js → result-contract.js → result-bridge.js`، اجرای نگهبان، سپس انتقال XP، رکورد و ستاره به سرویس واحد.

## ساختار مقصد

```text
src/
  domain/games/       # رجیستری، نتیجه، پیشرفت و اقتصاد
  games/              # موتور و رابط هر بازی
  features/catalog/   # صفحهٔ بازی‌ها و فیلترها
  shared/              # صدا، دسترس‌پذیری، ابزارهای RTL
public/games/         # خروجی قابل استقرار
```
