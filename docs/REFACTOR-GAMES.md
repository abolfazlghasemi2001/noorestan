# بازطراحی بازی‌های نورستان

شاخهٔ `refactor/game-catalog` فازهای اولیهٔ بازطراحی است. رفتار فعلی نسخهٔ اصلی دست‌نخورده مانده و تغییرات ابتدا روی شاخهٔ جدا انجام می‌شوند.

## انجام‌شده

1. رجیستری واحد بازی‌ها در `games/catalog.js`.
2. اتصال صفحهٔ `games/index.html` به رجیستری و فیلتر موضوع/مهارت.
3. قرارداد مشترک نتیجه در `games/result-contract.js` با سازگاری برای API قدیمی `G.result`.
4. آداپتور مهاجرت در `games/result-bridge.js`، آماده برای اتصال صفحات سه بازی بدون شکستن صفحهٔ نتیجهٔ فعلی.

## قدم بعدی

در commit بعدی، هر سه صفحهٔ بازی `ayah-builder.html`، `hadith-rush.html` و `noor-pairs.html` این دو فایل را پیش از اسکریپت خودشان بارگذاری می‌کنند. بعد از آن `G.result()` از قرارداد مشترک عبور می‌کند و تست مهاجرت اجرا می‌شود.

## ساختار مقصد

```text
src/
  domain/games/       # رجیستری، نتیجه، پیشرفت و اقتصاد
  games/              # موتور و رابط هر بازی
  features/catalog/   # صفحهٔ بازی‌ها و فیلترها
  shared/              # صدا، دسترس‌پذیری، ابزارهای RTL
public/games/         # خروجی قابل استقرار
```

## دسته‌بندی نهایی پیشنهادی

موضوع: آیات و سوره‌ها، حدیث و حکمت، معارف و دانستنی‌ها، نهج‌البلاغه، ادعیه، چندنفره.

مهارت: حافظه، سرعت، واژه، آزمون، رقابتی.

با سه بازی فعلی، دسته‌های موضوعی باید خلوت بمانند و فیلترها نقش اصلی را داشته باشند؛ برای هر بازی یک دستهٔ جدا نسازیم.

## خط قرمزها

- حذف مستقیم فایل‌های قدیمی ممنوع تا وابستگی‌شان مشخص شود.
- تغییر هم‌زمان قرارداد امتیاز در اپ اصلی و بازی مستقل ممنوع مگر با تست مهاجرت.
- بازی‌های `embedded` نباید به‌عنوان صفحهٔ مستقل و آماده نمایش داده شوند.
- نسخهٔ deploy با منبع قابل ویرایش قاطی نشود.
