# مرحلهٔ دوم — ایستگاه بازبینی پوسته

تاریخ: ۲۰۲۶/۰۹/۲۶ — **گزارش میانی، نه تحویل کامل درخواست ۱۳‌بندی**.

طبق ترتیب خواسته‌شده، فقط بازطراحی پوسته و شواهد قبل/بعد انجام شده است. ورود مهمان، Net محلی، OTP، مجوزهای مدیریت، پرداخت، سودوکو، راه‌اندازی مجدد بازی‌ها و خروجی شخصی هنوز در این مرحله تغییر نکرده‌اند. داده‌ها و منطق امتیاز، زنجیره و مأموریت‌ها دست‌نخورده‌اند.

## تغییرها

- `index.html`: جایگزینی مقدمهٔ خانه با صحن، تیتر تازه، تصویر معماری و دو دسترسی واقعی به تلاوت و بازی‌ها؛ شناسه‌های آمار موجود حفظ شده‌اند.
- `assets/styles/sanctuary.css`: پوستهٔ مشترک خانه، کارت‌ها، بازی‌ها، حساب، فرم‌ها، فروشگاه، تب‌ها، مدیریت و پنجره‌ها؛ سبز شب/طلایی و روشنِ سنگی، نوار ناوبری شناور و چیدمان واکنش‌گرا.
- `assets/images/sanctuary-court.svg`: نگارهٔ برداری دست‌نویس مسجد و صحن با پنجره‌های نورانی، گنبد و فانوس؛ بدون عکس، CDN یا کتابخانهٔ خارجی.
- `Install.place()` در `index.html`: فاصلهٔ پخش‌کننده و بنر نصب از موقعیت واقعی نوار شناور محاسبه می‌شود. در آزمون اولیه هم‌پوشانی مشاهده و پیش از تحویل اصلاح شد.
- `sw.js`: چهار نام کش به نسخهٔ ۲۱ رفتند؛ CSS و SVG تازه در پیش‌ذخیرهٔ پوسته هستند.
- `_tests.js` و `assets/README.md`: انتظار نسخهٔ کش/مستندات با نسخهٔ ۲۱ هماهنگ شد؛ آزمون‌های امنیتی حذف نشده‌اند.
- `_theme-review-tests.js`: ابزار بازتولید عکس‌ها و کنترل دو دسترسی تازه، چهار نمای داخلی، سرریز افقی و خطاهای مرورگر.

## شواهد تصویری

عکس‌ها از مرورگر واقعی محلی هستند، نه طرح گرافیکی یا تصویر تولیدشده:

- `screenshots/phase2-theme-before-after.png`: مقایسهٔ کنارهم دسکتاپ تیره و موبایل تیره/روشن.
- `screenshots/phase2-{before,after}-{dark,light}-{1440,390}.png`: هشت تصویر جداگانه.
- `screenshots/phase2-after-{play,quran,settings,shop}.png`: نماهای داخلی پس از تغییر.

در هر مقایسه، حساب آزمایشی، اندازهٔ صفحه و وضعیت کاهش حرکت یکسان است. پردهٔ آغازین/ورود فقط در اسکریپت عکس‌برداری کنار زده می‌شود؛ مسیر ورود تولیدی برای گرفتن عکس تغییر نکرده است. درخواست‌های خارجی در آزمون مسدودند؛ عکس تلاوت تأیید دریافت متن/صوت از اینترنت نیست. فایل‌های PNG مطابق قاعدهٔ قبلی مخزن در Git ثبت نمی‌شوند.

## نتیجهٔ بررسی‌ها

- `node _check-scripts.js`: موفق.
- `node --check sw.js` و `node --check _theme-review-tests.js`: موفق.
- `node _harness.js`: **۲۱۱۸ موفق، صفر ناموفق**.
- `_ui-update-tests.js`: **۹۶/۹۶**؛ دو تم، چهار اندازه، هشت نمای اصلی، کنترل کلیک/برش، فاصلهٔ بنر نصب/پخش، کاهش حرکت و قاب بازی. مشاهدهٔ گردش اسلایدر در این اجرا **۱۸٫۴ ثانیه** بود؛ این اجرای تازه، آزمون سه‌دقیقه‌ای نیست.
- `_theme-review-tests.js`: موفق؛ دو دکمهٔ تازه به صفحهٔ صحیح می‌روند؛ بدون خطای runtime، selfTest موفق، چهار نمای داخلی ثبت شد.
- همهٔ کامنت‌های فارسی بلوکی موجود در نسخهٔ پیش از این تغییر حفظ شده‌اند؛ `git diff --check` موفق.
- اندازهٔ دو منبع تازه: CSS برابر ۱۱٬۶۵۶ بایت و SVG برابر ۳٬۸۵۴ بایت؛ مجموع gzip محلی حدود ۴٫۷ کیلوبایت. این اندازه‌گیری جایگزین آزمون اتصال کند بند ۱۳ نیست؛ سرور باید فشرده‌سازی را فعال کند.

## اجرای دوباره

```bash
python3 -m http.server 8080 --bind 0.0.0.0
# در محیط دیگر یا ترمینال جدا؛ نیازمند Playwright و Chromium:
THEME_BASELINE=tmp/phase2/index.before.html node _theme-review-tests.js
CAROUSEL_MS=18000 node _ui-update-tests.js
node _harness.js
```

فایل baseline یک نسخهٔ موقت پیش از تغییر این جلسه است، نه بخشی از Git. بدون THEME_BASELINE، ابزار فقط عکس‌های بعد را می‌سازد. در محیط این جلسه، Chromium با `LD_LIBRARY_PATH="$PWD/tmp/chrome-libs/lib"` و `PW_TEST_SCREENSHOT_NO_FONTS_READY=1` اجرا شد.

## ادامهٔ کار

این گزارش تأیید بندهای دیگر نیست. URL عمومی سرور موجود هنوز ارائه نشده؛ آزمون واقعی پیامک/شبکه به آن نیاز دارد. پرداخت انتخاب‌شده آزمایشی است و حساب پذیرندگی موجود نیست. چندنفرهٔ واقعی بازی خارجی بدون سورس یا API آن قابل پیاده‌سازی/تأیید نیست. جلسهٔ GitHub قبلی بسته شده است؛ انتشار این تغییرهای محلی به جلسهٔ کدنویسی جدید نیاز دارد.
