### محدودیتِ باز و شرط انتشار

درخواست مستقیم به آدرس Arena، چه با curl و چه با مرورگر Chromium محیط، با `ERR_CONNECTION_CLOSED`/خطای TLS متوقف شد. ابزار دریافت محتوای صفحه عنوان و معرفی بازی را نشان داد، اما این برای بازی‌کردن و سنجش canvas/گزینه‌ها کافی نیست. سورس آن پروژه نیز در checkout نورستان وجود ندارد.

بنابراین **نمی‌توان تأیید کرد یک دور کاملِ نسخهٔ سه‌بعدی روی موبایل/دسکتاپ بازی شده یا همهٔ گزینه‌های داخل آن در همهٔ اندازه‌ها داخل کادر هستند**. برای بستن کامل بند ۲۷ باید روی آدرس قابل‌دسترسی، بازی واقعی اجرا و در صورت نیاز سورس پروژهٔ Arena اصلاح شود. آزمون لمس اینجا خودکار مرورگر است؛ چرخش واقعی دستگاه/iOS و تمام‌صفحهٔ Safari هنوز آزمون دستی لازم دارند.

محدودیت امنیتیِ شمارندهٔ مدیر نیز روشن است: روی سایت استاتیک، کاربرِ دارای دسترسی به حافظهٔ مرورگر می‌تواند قفل محلی را پاک کند؛ این تأخیر جای rate limit سمت سرور را نمی‌گیرد.

## بازتولید

```sh
node _check-scripts.js
node _harness.js
node --check sw.js

# فقط ابزار توسعه؛ وابستگی زمان اجرای سایت نیست
npm install --no-save --no-package-lock playwright @sparticuz/chromium
python3 -m http.server 8080 --bind 0.0.0.0
# در ترمینال دیگر؛ Chromium نصب‌شده را هم می‌توان با CHROMIUM_PATH معرفی کرد
BASE_URL=http://localhost:8080 CAROUSEL_MS=180000 node _ui-update-tests.js
```

در این محیطِ کمینه، کتابخانه‌های NSS لازم برای Chromium از بستهٔ توسعهٔ Chromium در `tmp/chrome-libs` استخراج شدند و `LD_LIBRARY_PATH` به آن اشاره داشت؛ در محصول هیچ کدام لازم نیست. خروجی خام، تصاویر و بسته‌های ابزار در `tmp/` و `node_modules/` هستند و وارد Git نمی‌شوند.

فایل‌های اصلیِ تغییر: `index.html`، `sw.js`، `_tests.js`، `_check-scripts.js`، `_ui-update-tests.js`، مستندات، قلم/مجوز لاله‌زار و سه SVG داخل `assets/images/promo/`. دیف کاملِ قابل‌اعمال همراه فایل تحویل `noorestan-update.patch` ارائه می‌شود؛ فایل binary فونت هم در آن هست.
