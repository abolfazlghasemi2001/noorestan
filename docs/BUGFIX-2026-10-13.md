```
node --check (هر فایلِ دست‌خورده) → node _check-scripts.js → node _harness.js
```

> ⚠️ **در این محیط هیچ مرورگری نصب نیست** (chromium/chrome/firefox نبودند و
> puppeteer/playwright هم قابلِ نصب نیست). پس **هیچ تأییدِ بصریِ واقعی انجام نشده است**:
> راستی‌آزمایی‌ها از راهِ هارنسِ Node با DOMِ استاب، تحلیلِ آبشاریِ CSS
> (`/tmp/cascade.py`)، و سنجش‌های منبع‌محور بوده است. پیش از انتشار باید
> `NOOR_BROWSER_GATE=1 bash tools/ci.sh` و `node _ayah-vertical-tests.js`
> روی دستگاهِ دارای مرورگر اجرا شود.

هر سنجشِ تازه‌ای که نوشته شده، **پیش از رفعِ ایراد قرمز بوده** تا از «سنجشِ همیشه‌سبز»
