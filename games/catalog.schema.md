# قرارداد فهرست بازی‌ها

این فایل قرارداد مشترک کاتالوگ است. هر بازی باید در `games/catalog.js` یک رکورد داشته باشد.

## دسته‌بندی

- `subject` موضوع آموزشی است: آیات و سوره‌ها، حدیث و حکمت، معارف و دانستنی‌ها، نهج‌البلاغه، ادعیه، چندنفره.
- `skills` شیوهٔ بازی است: حافظه و تمرکز، سرعت و واکنش، چیدن و واژه‌ها، آزمون و چهارگزینه‌ای، رقابتی.
- این دو را قاطی نکنیم. «حافظه» دستهٔ اصلی نیست، فیلتر مهارتی است.

## وضعیت

- `available`: صفحهٔ مستقل و قابل اجرا
- `embedded`: قابلیت موجود در اپ اصلی
- `planned`: ایده یا بازی آینده، هنوز در دسترس نیست
- `hidden`: برای نگه‌داری داده، نه نمایش به کاربر

## قرارداد هر بازی

```js
{
  id, title, description,
  subject, skills: [], modes: ['solo' | 'online'],
  difficulty: ['easy' | 'medium' | 'hard'],
  duration, timed, offline,
  status, route, art, scoreKeys: []
}
```

## اصل مهم

امتیاز، XP، ستاره، رکورد و چالش روزانه نباید در هر بازی دوباره پیاده‌سازی شود. بعد از فاز استخراج، همهٔ بازی‌ها فقط نتیجه‌ای با این شکل تحویل می‌دهند:

```js
{ gameId, score, stars, completion, metadata }
```
