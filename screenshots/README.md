# اسکرین‌شات‌های نورستان

این پوشه جای عکس‌های `_shots.js` است. روی این دستگاه **خالی ماند** — دلیلش
پایین آمده و راه‌های جایگزین هم هست.

---

## ۱. چرا روی این دستگاه نشد

Puppeteer با `npm` نصب شد (۲۷ بسته، بدون خطا)، ولی خودِ مرورگر دانلود نشد:

```
Browser download failed
Error: The current platform is not supported.
    at downloadBrowsers (node_modules/puppeteer/lib/puppeteer/node/install.js:43:15)
```

`@puppeteer/browsers` برای اندروید/arm64 هیچ نسخه‌ای از Chrome for Testing
ندارد، پس حتی تلاش هم نمی‌کند دانلود کند. این یک مشکل مجوز یا تنظیمات نیست
که با پرچم حل شود:

| بررسی | نتیجه |
|---|---|
| معماری | `aarch64` / `arm64-v8a` |
| کتابخانهٔ C | Bionic (`/system/lib64/libc.so`) — اندروید |
| glibc | نیست (`/lib64/ld-linux-aarch64.so.1` وجود ندارد) |
| `proot` / `proot-distro` | نصب نیست |
| پشتیبانی سیم‌لینک در `/storage/emulated/0` | ندارد (FUSE) |

حتی اگر باینری Chrome جایی پیدا می‌شد، glibc‌محور است و روی Bionic اجرا
نمی‌شود. دو مسیر اندرویدی هم آزموده و بسته شد:

- `/system/bin/screencap -p` → کد خروج ۱، فایل صفر بایت (مجوز فریم‌بافر ندارد)
- `/system/bin/input tap` → استثنا می‌دهد (تزریق ورودی ممنوع است)

پس روی همین گوشی، اسکرین‌شات خودکار ممکن نیست. `_shots.js` سالم و آماده است
و روی رایانهٔ معمولی کار می‌کند.

---

## ۲. اجرا روی رایانهٔ دیگر

```bash
# ۱. کل پوشهٔ نورستان را کپی کن (یا فقط _shots.js و _shots_env)
# ۲. نصب — حتماً روی فایل‌سیستمی که سیم‌لینک پشتیبانی می‌کند
cd _shots_env && npm install

# ۳. اجرا از ریشهٔ برنامه
cd ..
node _shots.js
```

خروجی در `screenshots/` با نام‌های شماره‌دار می‌آید.

### پرچم‌ها

| پرچم | کار |
|---|---|
| `--out=مسیر` | پوشهٔ خروجی (پیش‌فرض `screenshots`) |
| `--port=8801` | پورت سرور موقت (پیش‌فرض ۸۷۹۹) |
| `--admin-pass=رمز` | رمز پنل مدیر (پیش‌فرض `noor2024`) |
| `--all-games` | بازی‌های دیگر لانچر را هم می‌گیرد (حدیث‌یاب، چهارده معصوم، نجوا، نهج‌البلاغه، آزمون معارف، …) |
| `--keep-anim` | انیمیشن‌ها را نمی‌خواباند (عکس‌ها یک‌تکرار نمی‌مانند) |

اسکریپت خودش `server.js` را روی یک پورت آزاد بالا می‌آورد و آخرش می‌بندد،
چون صفحهٔ «محفل» و «روم» به WebSocket همان سرور وصل می‌شوند. با یک سرور
ایستای ساده، آن دو صفحه در حالت قطع عکس می‌افتند.

پیش از هر عکس **۶۰۰ms** صبر می‌کند و ویوپورت **۳۹۰×۸۴۴** با چگالی ۲ است.

### چرا بعضی صفحه‌ها را با کلیک نمی‌گیرد

- **روم**: تابع `renderRoom()` اگر `Net.room` نباشد بی‌درنگ برمی‌گردد. اسکریپت
  یک روم نمونه با پنج عضو می‌سازد تا صفحه واقعاً کشیده شود.
- **پنل مدیر**: پشت رمز است. اسکریپت با رمز پیش‌فرض وارد می‌شود؛ اگر رمز
  عوض شده باشد، عکسِ *دروازهٔ ورود* می‌افتد — که خودش هم صفحهٔ معتبری است.

## ۳. اگر Puppeteer نداری: دستی عکس بگیر

روی همین گوشی هم می‌شود: نورستان را در Chrome باز کن و با **دکمهٔ پاور +
کم‌کردن صدا** عکس بگیر.

نخست سرور را بالا بیاور و آدرس را در Chrome باز کن:

```bash
node server.js          # پورت پیش‌فرض ۸۷۸۷
# سپس در Chrome:  http://localhost:8787/index.html
```

> **مهم:** فایل را با `file://` باز نکن. در `file://` بافت امن برقرار نیست و
> `crypto.subtle` تعریف نشده می‌ماند؛ آن‌وقت ورود مدیر و ذخیرهٔ سوره‌ها
> کار نمی‌کند. حتماً از راه سرور باز کن.

### الف) صفحه‌هایی که نشانی مستقیم دارند

این‌ها را می‌شود مستقیم در نوار نشانی زد. Router هنگام بارگذاری، هش را
می‌خواند و همان صفحه را می‌کشد:

| # | نشانی | صفحه |
|---|---|---|
| ۰۱ | `#home` | خانه |
| ۰۲ | `#online` | محفل |
| ۰۳ | `#notif` | اعلان |
| ۰۴ | `#admin` | پنل مدیر (رمز پیش‌فرض: `noor2024`) |
| ۰۵ | `#room` | روم — **بی‌روم خالی می‌ماند**، پایین را ببین |
| ۱۶ | `#quran` | تلاوت قرآن |
| — | `#read` | مصحف‌نما (اضافه) |
| — | `#play` | همهٔ بازی‌ها |
| — | `#me` | «من» — تب پیش‌فرض «آمار» است |
| — | `#join=CODE` | پیوند دعوت به روم |

**`#room` خالی می‌ماند** مگر آنکه واقعاً در رومی باشی. برای عکس گرفتن از آن:
محفل → «ساخت روم» → آن‌گاه وارد روم شو، یا با دو نفر یک روم بساز.

### ب) بازی‌ها — نشانی ندارند

بازی‌ها با تابع `Games[id]()` اجرا می‌شوند، نه با مسیر. پس باید کلیک کنی:

**نوار پایین → 🎮 بازی** (یا `#play`) → کاشی بازی.

| # | نام فایل هدف | بازی | مسیر کلیک |
|---|---|---|---|
| ۰۶ | `06-quiz` | سوالات قرآنی 📚 | 🎮 بازی → کاشی «سوالات قرآنی» |
| ۰۷ | `07-surah` | سفر سوره‌ها 📖 | 🎮 بازی → «سفر سوره‌ها» |
| ۰۸ | `08-scramble` | پازل حروف 🧩 | 🎮 بازی → «پازل حروف» |
| ۰۹ | `09-memory` | حافظه 🧠 | 🎮 بازی → «حافظه» |
| ۱۰ | `10-match` | تطبیق 🔗 | 🎮 بازی → «تطبیق» |
| ۱۱ | `11-dooz` | دوز ❌⭕ | 🎮 بازی → «دوز» |
| ۱۲ | `12-esmfamil` | اسم فامیل 📝 | 🎮 بازی → «اسم فامیل» |
| ۱۳ | `13-iran` | اطلاعات ایران 🇮🇷 | 🎮 بازی → «اطلاعات ایران» |
| ۱۴ | `14-meaning` | معنی کلمه 🔤 | 🎮 بازی → «معنی کلمه» |
| ۱۵ | `15-speed` | سرعت نور ⚡ | 🎮 بازی → «سرعت نور» |

> دربارهٔ «۱۰ بازی»: تو ۹ نام بردی (quiz، surah، scramble، memory، match،
> dooz، esmfamil، iran، meaning) و گفتی ۱۰ بازی. دهمی را **سرعت نور** گذاشتم
> چون از بقیه بازی‌گونه‌تر است. اگر منظورت چیز دیگری بود، لانچر این‌ها را هم
> دارد: حدیث‌یاب، چهارده معصوم، نجوا، نهج‌البلاغه، آزمون معارف، چالش روزانه.
> با `--all-games` همه‌شان گرفته می‌شوند.

### ج) مودال‌ها — تب‌های «من»

**نوار پایین → 👤 حساب**، بعد تب:

| # | نام فایل هدف | تب |
|---|---|---|
| ۱۷ | `17-modal-settings` | ⚙️ تنظیمات |
| ۱۸ | `18-modal-stats` | 📊 آمار |
| ۱۹ | `19-modal-badges` | 🎖️ نشان‌ها |
| ۲۰ | `20-modal-leaderboard` | 🏅 رکوردها |

### د) حالت اشکال‌زدایی

| # | نشانی | صفحه |
|---|---|---|

## ۵. نکته‌ای که ارزش دیدن دارد

اسکریپت خطاهای Console را جمع می‌کند و در گزارش آخر چاپ می‌کند، چون قاعدهٔ
خودِ پروژه «صفر خطای Console» است. خطاهای شبکه (API قرآن، فونت بیرونی) عمداً
نادیده گرفته می‌شوند — در محیط بستهٔ اسکرین‌شات اجتناب‌ناپذیرند و ربطی به
سلامت رندر ندارند.
