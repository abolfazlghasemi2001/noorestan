# اسکرین‌شات‌های نورستان

این پوشه جای عکس‌های `_shots.js` است. **راهنمای کامل در `_shots-guide.md`
در ریشهٔ برنامه است** — فهرست نشانی‌ها، چک‌لیست عکس‌ها، و راه اجرا روی
رایانه. این فایل فقط برای آن است که اگر کسی مستقیم به این پوشه سر زد،
گم نشود.

کوتاه: روی همین گوشی عکس‌گرفتن خودکار ممکن نیست (برای اندروید/arm64
نسخه‌ای از Chrome for Testing وجود ندارد و باینری‌های موجود glibc‌محورند).
دستی با **پاور + کم‌کردن صدا** عکس بگیر، یا `_shots.js` را روی رایانه
اجرا کن.
